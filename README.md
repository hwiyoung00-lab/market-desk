# 마켓 데스크 — 설치 안내

GitHub을 한 번도 안 써봤다는 전제로 씁니다. 순서대로만 따라오세요.
**API 키는 하나도 필요 없습니다.** 신용카드도, 결제도 없습니다.

전부 다 해서 **20~30분**쯤 걸립니다.

---

## 이게 어떤 구조인지 30초 요약

```
GitHub Actions   평일 정해진 시각에 깨어나서
      ↓          야후 파이낸스에서 시세를 받아옵니다
data/latest.json 결과를 이 파일에 저장(커밋)합니다
      ↓
GitHub Pages     index.html 을 웹에 띄워줍니다
      ↓
내 페이지        같은 폴더의 latest.json 만 읽어서 그립니다
```

**왜 굳이 이렇게 하나** — 브라우저는 보안 규칙(CORS) 때문에 야후 파이낸스를
직접 못 부릅니다. 하지만 GitHub Actions는 브라우저가 아니라 서버라서
그 규칙이 적용되지 않습니다. 그래서 "받아오는 일"은 Actions가 하고,
"보여주는 일"만 브라우저가 합니다.

---

## 1단계 — GitHub 계정 만들기

1. <https://github.com/signup> 접속
2. 이메일 → 비밀번호 → 원하는 아이디(username) 입력
   - **이 아이디가 나중에 주소가 됩니다.** `아이디.github.io/market-desk`
   - 영문 소문자와 숫자로, 짧고 단정하게 정하세요. 나중에 바꾸기 번거롭습니다.
3. 이메일로 온 인증 코드 입력
4. 요금제를 고르라고 하면 **Free** 선택

---

## 2단계 — 저장소(repository) 만들기

"저장소"는 그냥 **프로젝트 폴더 하나**라고 생각하면 됩니다.

1. 오른쪽 위 `+` → **New repository**
2. **Repository name**: `market-desk`
3. **Public** 선택
   - ⚠️ **Private로 하면 GitHub Pages가 무료 요금제에서 안 됩니다.**
   - 여기 올라가는 건 공개 시세와 내 관심종목 목록뿐입니다. 계좌·잔고·매수단가는
     어디에도 안 들어갑니다. 그래도 관심종목 목록조차 남에게 보이기 싫다면
     `config.json`의 종목을 대표 지수 위주로 바꿔 두세요.
4. 나머지는 건드리지 말고 **Create repository**

---

## 3단계 — 파일 올리기

1. 방금 만든 저장소 화면에서 **uploading an existing file** 링크 클릭
   (안 보이면 `Add file` → `Upload files`)
2. 받으신 압축을 푼 **`market-desk` 폴더 안의 내용물 전부**를 드래그해서 올립니다
   - `market-desk` 폴더 자체가 아니라 **그 안의 것들**입니다
   - `index.html`, `config.json`, `README.md`, 그리고 `config` / `data` / `scripts` / `.github` 폴더
3. 아래 **Commit changes** 버튼 클릭

> **`.github` 폴더가 안 올라간다면**
> 이름이 점(.)으로 시작해서 파일 탐색기에서 숨겨져 있을 수 있습니다.
> - Windows: 탐색기 상단 `보기` → `숨긴 항목` 체크
> - Mac: Finder에서 `⌘ + Shift + .`
>
> 그래도 안 되면 저장소에서 `Add file` → `Create new file`을 누르고
> 파일 이름 칸에 `.github/workflows/update.yml` 을 그대로 치면 폴더가 자동으로
> 만들어집니다. 거기에 파일 내용을 붙여넣고 저장하세요.

---

## 4단계 — Actions에 쓰기 권한 주기

수집 결과를 저장소에 커밋해야 하므로 권한이 필요합니다. **이 단계를 빠뜨리면
수집은 되는데 저장이 안 됩니다.**

1. 저장소 상단 **Settings** 탭
2. 왼쪽 메뉴 아래쪽 **Actions** → **General**
3. 맨 아래 **Workflow permissions** 항목에서
   **Read and write permissions** 선택
4. **Save**

---

## 5단계 — 웹에 띄우기 (GitHub Pages)

1. **Settings** → 왼쪽 메뉴 **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / 폴더는 `/ (root)` → **Save**
4. 1~2분 기다린 뒤 새로고침하면 주소가 나옵니다

```
https://내아이디.github.io/market-desk/
```

이 주소로 들어가면 화면이 뜹니다. **여기까지 하면 일단 완성입니다.**
(첫 화면은 제가 넣어둔 9월 4일자 값입니다.)

---

## 6단계 — 수집을 한 번 직접 돌려보기

예약 시각까지 기다리지 말고 지금 확인해 봅시다.

1. 저장소 상단 **Actions** 탭
2. 처음이면 노란 배너에서 **I understand my workflows, go ahead and enable them** 클릭
3. 왼쪽에서 **시세 갱신** 선택
4. 오른쪽 **Run workflow** → 초록 버튼 **Run workflow**
5. 1~2분 뒤 새로고침. **초록 체크 ✓** 가 뜨면 성공입니다

성공했다면 페이지를 새로고침해 보세요. 최종 갱신 시각이 방금으로 바뀌어 있습니다.

**빨간 X가 떴다면** — 실패한 줄을 클릭하면 로그가 나옵니다. 어느 단계에서
무슨 메시지가 났는지 저에게 그대로 보여주시면 봐 드리겠습니다.

## 이제 내 맞춤으로 바꾸기

### 관심종목 추가·삭제 → `config.json`

저장소에서 `config.json` 클릭 → 연필 아이콘 ✏️ → 고치고 → **Commit changes**

```json
{ "name": "한화오션", "symbol": "042660.KS", "market": "KOSPI" }
```

**symbol 규칙**

| 시장 | 형식 | 예시 |
|---|---|---|
| 코스피 | 6자리 + `.KS` | 삼성전자 `005930.KS` |
| 코스닥 | 6자리 + `.KQ` | 아이티센글로벌 `124500.KQ` |
| 미국 | 티커 그대로 | `NVDA`, `TSLA` |
| ETF | 티커 그대로 | `SPY`, `TLT` |

> 잘 모르겠으면 야후 파이낸스에서 검색해 보세요.
> `https://finance.yahoo.com/quote/005930.KS` 처럼 페이지가 열리면 맞는 것입니다.

지수(`indices`)와 환율·원자재(`macro`)도 같은 방식으로 바꿉니다.
`^KS11`(코스피), `^VIX`, `KRW=X`(원/달러), `GC=F`(금), `CL=F`(WTI) 같은 것들입니다.

### 경제 일정 → `config/calendar.json`

일정은 자동 수집이 안 됩니다(무료로 믿을 만한 공개 소스가 없습니다).
이 파일에 직접 적어 넣으세요. 한 달에 한 번 5분이면 됩니다.

### 갱신 시각 → `.github/workflows/update.yml`

```yaml
- cron: "0 7 * * 1-5"    # UTC 07:00 = 한국 16:00
```

**cron은 UTC 기준입니다. 한국시간에서 9시간을 빼세요.**
한국 오후 3시 40분에 돌리고 싶다면 `40 6 * * 1-5` 입니다.

---

## 미리 알아둘 것

**갱신은 정시가 아닙니다.** GitHub의 예약 실행은 전 세계가 같이 쓰는 자원이라
혼잡하면 몇 분에서 몇십 분까지 밀립니다. 급하면 Actions 탭에서 직접 돌리세요.

**60일 규칙.** 저장소에 60일 동안 아무 활동이 없으면 GitHub이 예약 실행을
자동으로 멈춥니다. 이 프로젝트는 갱신될 때마다 커밋이 쌓여서 보통 걸리지
않지만, 장기 휴장이나 연속 실패가 겹치면 멈출 수 있습니다. 페이지의
'최종 갱신'이 며칠째 그대로면 Actions 탭을 확인하세요.

**야후 파이낸스는 공식 API가 아닙니다.** 개인용으로 오래 쓰여왔지만 야후가
언제든 막을 수 있습니다. 그래서 수집기에 stooq 예비 경로를 넣어뒀고, 둘 다
실패하면 직전 값을 유지하면서 화면에 `이전 값` 배지를 띄웁니다.
**틀린 숫자를 보여주느니 오래된 숫자임을 밝히는 쪽**을 택한 설계입니다.

**실시간이 아닙니다.** 하루 두 번입니다. 매크로와 관심종목을 확인하는
용도이지, 호가를 보며 매매하는 화면이 아닙니다.

## 파일이 뭐가 뭔지

| 파일 | 역할 | 내가 고칠 일 |
|---|---|---|
| `index.html` | 화면 전부 (디자인·렌더링) | 디자인 바꿀 때만 |
| `config.json` | **무엇을 볼지** | **자주** |
| `config/calendar.json` | 경제 일정 | 월 1회 |
| `scripts/collect.py` | 데이터 수집기 | 거의 없음 |
| `.github/workflows/update.yml` | 언제 돌릴지 | 시각 바꿀 때 |
| `data/latest.json` | 수집 결과 | **직접 고치지 마세요** — 다음 갱신 때 덮어씁니다 |

## 다음에 해볼 만한 것

- **개인 도메인 붙이기** — Settings → Pages → Custom domain. 도메인은 연 2만원쯤.
- **차트 넣기** — 야후 응답에 이미 5일치 일봉이 들어 있습니다. 스파크라인 정도는 라이브러리 없이도 그려집니다.
- **직접 계산한 지표** — 금/실질금리 스프레드처럼 남이 안 주는 값을 `collect.py`에서 계산해 넣을 수 있습니다. **이게 남의 위젯을 붙이는 것과 갈라지는 지점입니다.**
- **알림** — 관심종목이 ±5% 넘게 움직이면 Actions에서 메일이나 텔레그램으로 쏘기.

막히면 어느 단계에서 뭐가 안 되는지 말씀해 주세요.
