등락 색상은 한국 관행을 따릅니다 — 빨강 = 상승, 파랑 = 하락. 미국 종목·지수도 같은 규칙입니다.
갱신 방식 — GitHub Actions가 평일 한국시간 16:00과 다음날 07:00에 야후 파이낸스에서 값을 받아 data/latest.json에 커밋합니다. 이 페이지는 그 파일만 읽습니다. 실시간 시세가 아니며, 각 행의 기준 날짜를 확인하세요. 이전 값 표시는 이번 수집에서 값을 못 받아 직전 값을 그대로 둔 항목입니다.
바꾸고 싶으면 — 종목·지표는 config.json, 경제 일정은 config/calendar.json을 고치면 됩니다.
면책 — 투자 판단의 근거로 삼기 전 원 출처에서 반드시 재확인하세요. 이 페이지는 투자 자문이 아닙니다.
